## Why

A working final app does not make a teachable live course. Each lesson needs a runnable starting point, an exact coding script that fits a podium monitor, and a catch-up solution branch.

## What Changes

- Create six ordered lesson checkpoints from starter to final solution.
- Add Markdown lesson pages with exact contextual diffs or complete new-function code blocks.
- Host the notes locally with VitePress, alongside the lab.
- Document schedule, demos, failure experiments, setup, and safe catch-up commands.
- Add a branch-diff checker so displayed code remains aligned with the solution snapshots.

## Capabilities

### New Capabilities

- `workshop-lessons`: Reproducible branches and presenter-friendly, verifiable notes.

### Modified Capabilities

None.

## Impact

Adds `lesson-1` through `lesson-6` and `complete` Git branches, six pages under `lessons/`, a local notes theme, authoring script, and course setup documents.
